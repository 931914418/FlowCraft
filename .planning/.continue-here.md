> Acknowledge each one explicitly before proceeding.

- [ ] CONSTRAINT: **SSE event names must match between engine and route** — Engine emits `node:${execId}:${nodeId}`, SSE route must listen on `node:${execId}`. Fixed by adding unified event emission in engine.ts. If adding new events, always emit BOTH `node:${execId}:${nodeId}` AND `node:${execId}`.
- [ ] CONSTRAINT: **SSE data format is `event: xxx\ndata: yyy\n\n`** — Frontend must parse event/data as separate lines, NOT try to JSON.parse each line. The previous parser split on `:` and tried to parse the right side as JSON, which failed on `event: status` lines.
- [ ] CONSTRAINT: **No "fixed" claim without browser verification** — User caught premature claims multiple times. CLAUDE.md Step 3 is mandatory: restart service → Ctrl+Shift+R → end-to-end browser test → collect evidence.
