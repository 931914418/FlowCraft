# BLOCKING CONSTRAINTS — Read Before Anything Else

> These are not suggestions. Each constraint below was discovered through failure.
> Acknowledge each one explicitly before proceeding.

- [ ] CONSTRAINT: **SQLite 只能绑定基础类型** — Date 对象和嵌套 JSON 不能直接绑定，必须序列化为 string。结构化修复：engine 中用 `isSqlite` 检测，Date → `.toISOString()`，JSON → `JSON.stringify()`
- [ ] CONSTRAINT: **PG schema 不能传给 SQLite drizzle** — db/index.ts 需根据 `DB_DRIVER` 动态选择 schema，否则 `gen_random_uuid()` 不存在
- [ ] CONSTRAINT: **drizzle text(mode:'json') 写入时自动序列化** — 不要手动 `JSON.stringify()`，让 drizzle 处理。但读取时返回的是对象，只有 `updatedAt: Date` 需要手动转 ISO string

**Do not proceed until all boxes are checked.**

## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| 手动 JSON.stringify() definition | drizzle 的 mode:'json' 已自动序列化，手动 stringify 会存双重序列化的字符串 | blocking | 让 drizzle 处理 JSON 列，只对 Date/time 用 toTimestamp() |
| 环境变量直接读取 | 在多 driver 场景下会加载错误的 schema | blocking | 始终通过 `db/index.ts` 导出，动态选择 schema |
| 前端 ScrollArea 嵌套 | Sheet 已有 overflow-auto，ScrollArea h-full 会冲突 | advisory | 移除 ScrollArea 包装，让父容器处理滚动 |

**Severity values:** `blocking` — resuming agent must pass understanding check before proceeding. `advisory` — important context, does not gate resumption.

## Critical Anti-Patterns (do NOT repeat these)
- **SQLite 类型绑定错误** → 在任何写入数据库的地方检查：Date 对象用 `.toISOString()`，JSON 对象让 drizzle 处理（它的 mode:'json' 会自动序列化），不要手动 stringify

- **ScrollArea 嵌套** → Sheet 等容器已有 overflow-auto 时不要嵌套 ScrollArea，会导致滚动冲突
