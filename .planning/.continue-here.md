# BLOCKING CONSTRAINTS — Read Before Anything Else

> These are not suggestions. Each constraint below was discovered through failure.
> Acknowledge each one explicitly before proceeding.

- [ ] CONSTRAINT: **Start 节点必须将 input 数据作为 output 传递** — engine.ts 中 start 节点返回 `return { output: context.variables.get('input'), tokens: 0 }`。如重构 start 节点，必须保留此行为。
- [ ] CONSTRAINT: **nodeOutputs 是单一数据源，variables 是派生视图** — 不要在两个 map 中独立存储相同数据。
- [ ] CONSTRAINT: **Condition V1 表达式不能自动迁移到 V2** — 必须用双执行器。
- [ ] CONSTRAINT: **CodeExecutor 需要 ENABLE_CODE_EXECUTION=1 环境变量** — new Function() RCE 风险。
- [ ] CONSTRAINT: **Webhook secret 必须使用 timingSafeEqual 比较** — 禁止用 `===`。
- [ ] CONSTRAINT: **better-sqlite3 native binding 需要 node-gyp rebuild** — pnpm install 不会自动编译。Windows 环境需 MSVC Build Tools。

**Do not proceed until all boxes are checked.**

## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Premature "fixed" claim | 声称修复仅基于 API 测试，无浏览器验证 | blocking | CLAUDE.md Step 3: restart → refresh → 端到端浏览器验证 |
| Dual storage divergence | 在 nodeOutputs 和 variables 中独立写入相同数据 | blocking | nodeOutputs = single source, variables = derived |
